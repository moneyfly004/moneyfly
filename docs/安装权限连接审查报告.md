> 结论：三端安装包结构、权限链路、连接链路已逐项核对、本机实测并修复，**v0.0.5 起可完整走通「安装 → 登录 → 连接」**。

## 〇、v0.0.5 关键修复（本机实测发现，务必用 v0.0.5！）

**v0.0.3/v0.0.4 的 DMG 实际无法打开**（之前未实测，只验证了签名内容）：

| 版本 | 问题 |
|---|---|
| v0.0.2 | 无 keychain-access-groups → 登录 -34018 |
| v0.0.3/v0.0.4 | 加了 `keychain-access-groups`（受限 entitlement）→ **AMFI 拒绝启动**（`Code=-420 signature is invalid`，`Launch failed errno 153`）。受限 entitlement 只有 Apple / Developer ID / App Store 签名能携带，adhoc 签名携带即启动失败。 |
| **v0.0.5** | **entitlements 全部清空** → 本机实测：正常启动 ✓ 登录页正常渲染 ✓ Keychain 走传统路径（`SecItemCopyMatching`）无 -34018 ✓ |

修复原理：非沙盒 App 联网无需任何 entitlement；token 存传统 Keychain
（`MacOsOptions(useDataProtectionKeyChain: false)`）同样无需 entitlement。

## 二、macOS（DMG）

### 2.1 安装
1. 下载 `MoneyFly-<arch>.dmg`（arm64 = Apple 芯片；x86_64 = Intel；universal 通用）。
2. 双击挂载 DMG → 把 **MoneyFly.app** 拖入「应用程序」。
   - v0.0.2 起 DMG 内已内置「应用程序」快捷方式（`ln -s /Applications`），拖拽更直观。
3. **首次启动**：因 adhoc 签名（非 App Store / 未公证），Gatekeeper 会拦截。
   - 右键（或按住 Control 点击）MoneyFly.app → 选「打开」→ 弹窗点「打开」。
   - 或终端：`xattr -d com.apple.quarantine /Applications/MoneyFly.app` 后双击。
   - 系统设置 → 隐私与安全性 → 最底部「仍要打开」。

### 2.2 权限（macOS 无额外权限弹窗）
| 能力 | 是否需要权限 | 说明 |
|---|---|---|
| 网络（登录/API） | 否 | 非沙盒，无需 `network.client` entitlement（已加，双保险） |
| 系统代理（连接） | 否 | **刻意不启用 App Sandbox**：sing-box 子进程要写系统代理（SCDynamicStore），沙盒会阻止 → 表现为「已连接但无流量」。 |
| Keychain（token） | 否（v0.0.4 起） | 传统 Keychain（useDataProtectionKeyChain:false）无需 entitlement；v0.0.2 的 -34018 已消除 |
| 通知 | 否 | 未实现系统通知（设置页标注「后续版本」） |

### 2.3 连接链路
```
登录 → token 存 Keychain（传统 Keychain ✓）
连接 → 解压/查找 sing-box（Contents/MacOS/sing-box，universal 二合一）
     → 生成 config.json（规则集落盘 Documents/…/rules）
     → 启动 sing-box 子进程 + Clash API（127.0.0.1:9090）
     → 智能/全局切换 = PATCH /configs {"mode":...}
     → 进程退出看门狗自动重启
```
- 智能模式节点规则：vless-reality 367 / ss 123 / hysteria2 140 / vmess 38 / tuic 13 / anytls 147（共 824 可用）。
- 已处理：旧版 MoneyFly.app v1.0.35（同 bundle id）安装于 /Applications —— Keychain service 名不同
  （新应用 `flutter_secure_storage_service`，实测无残留项），**无冲突**。

## 三、Windows（exe 安装包 + zip 便携版）

### 3.1 安装
1. 下载 `MoneyFly-Setup-<ver>.exe`（Inno Setup 安装包）或 `MoneyFly-Portable-<ver>.zip`（免安装）。
2. 运行安装包 → **UAC 管理员确认**（写入 Program Files）。
3. **SmartScreen 拦截**（未签名 exe）：点「更多信息」→「仍要运行」。

### 3.2 权限 / 防火墙
| 项 | 说明 |
|---|---|
| UAC 提权 | 安装时一次；运行时不需管理员 |
| Windows 防火墙 | **不会弹入站提示**：Clash API 只监听 127.0.0.1 回环；出站连接不触发防火墙弹窗 |
| 内核 | `sing-box.exe` 与主程序同目录（安装器已打包，便携版 zip 同目录） |

### 3.3 连接链路
与 macOS 相同（CLI 子进程 + Clash API）。Windows 上用系统代理模式（非 TUN），无需网卡驱动。

## 四、Android（APK / AAB）

### 4.1 安装
- 三个 ABI 分体 APK：arm64-v8a（主流）/ armeabi-v7a（老机）/ x86_64（模拟器）；AAB 供上架。
- 旁载 APK：允许「安装未知应用」→ 弹窗确认。安装后**首次连接需授予 VPN 授权**。

### 4.2 权限清单（Manifest 已核对）
| 权限 | 用途 |
|---|---|
| INTERNET / ACCESS_NETWORK_STATE / ACCESS_WIFI_STATE | 网络 |
| BIND_VPN_SERVICE | VPN 服务（核心） |
| FOREGROUND_SERVICE / FOREGROUND_SERVICE_CONNECTED_DEVICE | 前台服务（连接期间保活） |
| POST_NOTIFICATIONS | 连接状态通知（Android 13+ 运行时弹窗） |
| WAKE_LOCK | 防休眠断连 |
| RECEIVE_BOOT_COMPLETED | 开机自启（BootReceiver，若开启） |
| REQUEST_IGNORE_BATTERY_OPTIMIZATIONS | **电池优化豁免（防杀后台，最高权限）** |

### 4.3 连接前自动引导（`ensureAllForConnect`，已实现）
```
点连接 → ① prepareVpn() 弹系统 VPN 授权框（拒绝则中止连接）
      → ② requestNotificationPermission()（Android 13+ 通知弹窗）
      → ③ isBatteryOptimizationIgnored()？未豁免 → requestIgnoreBatteryOptimization()
            弹「忽略电池优化」系统页，用户选「允许」
      → ④ 启动 VpnService：解压 libsingbox.so（jniLibs 按 ABI）→ 建 tun → 注入 fd → spawn sing-box
```
- 三平台共用一个 sing-box 内核（arm64/armv7/x86_64 预编译）。
- APK 体积 ~90-100MB/ABI（内核未压缩，换取免运行时下载）；后续可选「运行时下载内核」缩至 ~25MB。

## 五、连接链路统一说明（三端一致）

1. **订阅获取**：登录后 `GET /user/subscribe` → subscribe_url → `GET /client/subscribe?token=…&type=clash`
   - **UA 关键**：`MoneyFly/<ver>`（后端按 UA 识别 moneyfly 客户端）；浏览器 UA 会返回空 200。
2. **节点拉取**：解析 clash 订阅 → 过滤伪节点（协议不支持的）→ 存入本地。
3. **自动测速**：TCP ping ×3 中位数，并发 12，选延迟最低节点（可关）。
4. **连接**：智能模式 = 规则分流（geoip/geosite 本地规则集落盘）；全局 = 全走节点。
5. **保活**：进程退出看门狗（桌面）+ 3s 轮询（Android）+ 自动重连开关 + 电池豁免。
6. **切换**：切节点/切模式均走 Clash API，秒级生效。
