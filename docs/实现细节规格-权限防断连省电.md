# MoneyFly 客户端 · 实现细节规格（权限 / 防断连 / 省电 / 架构落地）

> 版本 v1.0 ｜ 配套设计稿 `design/`（14 张）｜ 后端 https://dy.moneyfly.top
> 本文件回答三个核心诉求：**最高权限防断连**、**省电防杀后台**、**完全参考小红鼠架构**。

---

## 1. 架构落地（对照小红鼠，逐项说明要不要）

小红鼠 Mac 版实测架构：**Flutter UI + libbox(sing-box Go 内核) + PacketTunnel.appex(Network Extension) + Clash API(流量/模式) + tray_manager + PostHog/Sentry + Tailscale(内置)**。

| 小红鼠组件 | 我们是否采用 | 说明 |
|---|---|---|
| Flutter UI | ✅ 采用 | 三端同构（macOS/Windows/Android），FVM 3.41.9 |
| sing-box 内核 | ✅ 采用 | 全协议 vless/vmess/trojan/ss/hysteria2/tuic/wireguard |
| libbox（cgo 编译进 Flutter 插件） | ✅ v2 采用 | macOS/iOS 用（与小红鼠一致，集成度最高） |
| sing-box CLI 子进程 | ✅ v1 采用 | Windows/macOS 先跑通，升级内核只换二进制 |
| libcore（go-mobile .aar） | ✅ Android 采用 | sing-box for Android 同款核心，配 VpnService |
| PacketTunnel.appex | ✅ v2 macOS | 系统级 VPN（需开发者证书 + entitlement + 公证） |
| 系统代理模式（v1 macOS/Windows） | ✅ v1 采用 | sing-box 起本地 mixed 端口 + `set_system_proxy`，免签名先跑通（**与 MoneyFly.app 现有行为一致**，实测其配置正是 `mixed + set_system_proxy`） |
| Clash API | ✅ 采用 | 流量统计 + 智能/全局热切换（`SetClashMode`），**切模式不断网** |
| Tailscale | ❌ 不采用 | 小红鼠内置（可能用于备用通道），我们不需要，减体积 |
| PostHog / Sentry | ◐ 可选 | 默认关（隐私设置里默认关，用户可开） |
| tray_manager / window_manager | ✅ 采用 | 桌面托盘常驻 + 窗口控制 |
| in_app_purchase | ❌ v1 | 官网直发模式，不走商店内购（v2 上架再考虑） |

## 2. 权限矩阵（三端「最高权限」配置）

> 原则：**只申请功能真实需要的权限**，但申请到的权限要用足——前台服务、系统级 VPN、电池优化豁免、开机自启、通知，全部主动引导授权，杜绝「半权限导致断连/被杀」。

### 2.1 Android（`android/app/src/main/AndroidManifest.xml`）

```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
<uses-permission android:name="android.permission.ACCESS_WIFI_STATE" />
<uses-permission android:name="android.permission.BIND_VPN_SERVICE" />          <!-- VpnService 核心 -->
<uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_CONNECTED_DEVICE" /> <!-- Android 14+ 前台服务类型 -->
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />         <!-- Android 13+ 通知 -->
<uses-permission android:name="android.permission.WAKE_LOCK" />                  <!-- 连接保活 -->
<uses-permission android:name="android.permission.RECEIVE_BOOT_COMPLETED" />     <!-- 开机自启 -->
<uses-permission android:name="android.permission.REQUEST_IGNORE_BATTERY_OPTIMIZATIONS" /> <!-- 电池优化豁免 -->
<uses-permission android:name="android.permission.VIBRATE" />
<uses-permission android:name="android.permission.QUERY_ALL_PACKAGES" tools:ignore="QueryAllPackagesPermission" />

<application ... android:requestLegacyExternalStorage="true">
  <service
      android:name=".vpn.MoneyFlyVpnService"
      android:exported="false"
      android:foregroundServiceType="connectedDevice"
      android:permission="android.permission.BIND_VPN_SERVICE">
    <intent-filter><action android:name="android.net.VpnService" /></intent-filter>
  </service>
  <receiver android:name=".vpn.BootReceiver" android:exported="true">
    <intent-filter>
      <action android:name="android.intent.action.BOOT_COMPLETED" />
      <action android:name="android.intent.action.QUICKBOOT_POWERON" />
    </intent-filter>
  </receiver>
</application>
```

**主动引导（连接时逐项检查，缺失就弹引导页，一次引导全）：**
1. `VpnService.prepare()` → 系统 VPN 授权弹窗；
2. `NotificationManager` 通知权限（Android 13+）；
3. `PowerManager.isIgnoringBatteryOptimizations == false` → 跳 `ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`；
4. **厂商后台白名单引导**（国内 ROM 杀后台重灾区）：检测 MIUI/EMUI/HyperOS/ColorOS/Funtouch 后，弹引导页告知去「电池/后台管理」设置允许自启动 + 后台运行 + 关联启动（附跳转 Intent：`com.miui.securitycenter` / `com.huawei.systemmanager` 等）；
5. 「开机自启」开关：`RECEIVE_BOOT_COMPLETED` + 厂商自启动引导。

### 2.2 macOS（`macos/Runner/DebugProfile.entitlements` / `Release.entitlements`）

```xml
<key>com.apple.security.app-sandbox</key><true/>
<key>com.apple.security.network.client</key><true/>      <!-- 访问后端/订阅 -->
<key>com.apple.security.network.server</key><true/>      <!-- 本地 mixed 代理端口 127.0.0.1 -->
<key>com.apple.security.files.user-selected.read-write</key><true/>
```

**v2 上 Network Extension 时追加（需 Apple Developer 账号）：**
```xml
<key>com.apple.developer.networking.networkextension.packet-tunnel-provider</key><true/>
```
- 打包：`codesign` 签名 → `notarytool` 公证 → 分发 dmg；未签名会触发 Gatekeeper 拦截（首次右键打开）。
- v1 系统代理模式**无需开发者证书**，适合先跑。

### 2.3 Windows（`windows/runner/Runner.rc` 嵌入 manifest）

```xml
<trustInfo xmlns="urn:schemas-microsoft-com:asm.v3">
  <security><requestedPrivileges>
    <requestedExecutionLevel level="requireAdministrator" uiAccess="false"/>
  </requestedPrivileges></security>
</trustInfo>
```
- **管理员权限**：WinTun 创建虚拟网卡必须；若用户拒绝 UAC，降级为「系统代理模式」继续可用（双通道设计）；
- **防火墙放行**（安装时执行，或首启引导）：`netsh advfirewall firewall add rule name="MoneyFly" dir=out action=allow program="<exe>"`；
- **开机自启**：注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 写入 exe 路径（普通权限可写）；
- **防断连**：内核以独立进程跑（`sing-box.exe`），主 UI 崩溃/退出不影响已建立的隧道；托盘常驻。

## 3. 防自动断连（核心诉求）

| 环节 | 措施 |
|---|---|
| 连接保活 | 内核层：hysteria2/tuic 自带心跳；vless/trojan 用 TCP keepalive + 每 30s 发送一次轻量探测（经代理 HEAD `http://www.gstatic.com/generate_204`，失败 2 次判定掉线） |
| 自动重连 | 断线检测（Clash API `/connections` 空 + 204 探测失败）→ 指数退避重连 **1s→2s→5s→10s**，最多 5 次；重连前自动重新测速，**换到当前最优节点**再连 |
| 热切换不断网 | 用户切节点/切国家/切模式：一律走 **Clash API 热更新**（`PATCH /configs` 改 selector / `SetClashMode`），**不重启内核、不断隧道** |
| 网络切换 | 监听 `ConnectivityManager`：WiFi→蜂窝/断网→恢复，触发一次快速重连（带 3s 去抖） |
| Android 防杀 | 前台服务 `START_STICKY`（系统杀死后自动重建）+ 高优先级常驻通知「MoneyFly 正在保护您的连接」+ 电池优化豁免 + 厂商自启动/后台白名单引导（见 §2.1）；**VpnService 本身是系统级通道，进程被杀会立刻重建** |
| Android 14+ | 前台服务必须声明 `connectedDevice` 类型 + 通知，否则运行中崩 → 已在 manifest 配置 |
| macOS | v2 用 Network Extension：**隧道由系统托管**，App 退出/崩溃隧道不断（这正是小红鼠方案）；v1 系统代理模式由托盘进程保活 |
| Windows | 内核独立进程 + 看护：UI 崩溃自动拉起内核；隧道由 WinTun 内核驱动承载，不随 UI 退出 |
| 电量/Doze | 前台服务 + 豁免后不受 Doze 深度限制；连接中持有 PARTIAL_WAKE_LOCK，空闲释放（见 §4） |
| 到期不踢线 | 订阅过期只提示续费，**不强制断开**（避免用户正在用突然断网）；后端侧若禁用订阅则照常断（受控） |

## 4. 省电设计（同时服务于「防杀后台」）

| 项目 | 策略 |
|---|---|
| 测速 | 连接前一次性**并发**测速（不是串行轮询）；后台测速默认 **30 分钟**一次且**仅已连接时**；低电量模式（`BatteryManager` ACTION_BATTERY_CHANGED <20%）自动暂停后台测速 |
| 流量统计 | 用内核推送事件（libbox `traffic` 回调 / Clash API 长轮询合并），**不做高频轮询**；UI 速率 1s 刷新，退后台降到 5s，断开后**完全停止刷新** |
| WakeLock | 仅连接建立、重连瞬间短持有（<5s）；空闲 15 分钟无流量自动释放；绝不常驻持有 |
| 通知 | 合并为单条常驻通知；到期提醒每日一次；避免频繁横幅 |
| DNS | sing-box 开 DNS 缓存；常用域名本地缓存 |
| 图形 | 断开时首页零动画、零定时器；连接中仅速率区 1Hz 动画 |
| Doze | 前台服务天然豁免大部分限制；不滥用 WorkManager 后台任务（省电+防杀双赢） |
| 进程模型 | Android 单进程 + 前台服务；桌面托盘常驻但空闲时零 CPU（内核空闲时 sing-box 本身几乎零占用） |

## 5. 全场景细节清单（把能想到的都列出来）

**认证与账号**
- 登录：账号/邮箱 + 密码；JWT access+refresh 自动续期（401 静默刷新后重试原请求）；
- 自动登录（开关，默认开）；多设备登录被踢 → 提示重新登录；
- 注册：邮箱验证码（60s 重发 / 5 分钟有效 / 用途隔离）；邀请码选填；协议勾选；
- 忘记密码：邮箱验证码两步重置；修改密码（登录态，需验证码）；
- 注册被后台关闭、邮箱已占用、验证码错误/过期 → 明确中文提示。

**订阅与节点**
- 订阅缓存：内存 + 本地（启动秒开），手动刷新 + 每 30 分钟静默刷新；
- 节点解析：Clash YAML + v2ray base64 双格式；解析失败给「订阅格式错误」+ 复制原文排查；
- 节点搜索（名称/地区/协议）、按地区分组折叠、按延迟排序；
- 测速：TCP ping 并发（默认 16 并发，控制瞬时 CPU）；延迟徽标颜色规则；「最优」标记；
- 快速切换国家：国家网格显示该国最低延迟，点按切换；「自动最优」回全局选优；
- 协议过滤（设置里可排除某类协议节点）。

**连接与模式**
- 智能模式：geoip cn / geosite cn → direct，其余 proxy；规则集定期更新（可本地兜底）；
- 全局模式：全部流量 proxy，仅放行本地/局域网；
- 切模式/切节点热更新不断网；断线自动重连 + 重选最优节点；
- 流量实时速率显示（不限流量，无用量统计）；连接耗时统计。

**套餐与支付**
- 套餐列表来自后端 `/packages`（不写死）；「最划算」由后端 is_recommended 驱动；
- 优惠码：输入→验证→折扣实时显示；
- 支付方式列表来自 `/payment/methods`，跟随官网设置（默认支付宝）；
- 下单 → 二维码弹窗（qr_flutter）→ 轮询 2.5s/次，15 分钟超时；成功自动刷新订阅并**自动连接**；
- 二维码支持点按放大 + 保存截图 + 复制订单号；「我已支付」手动刷新；
- 重复下单/未支付订单：进入订单确认前检查并提示「继续支付」；
- 支付成功但订阅未生效的兜底：强制刷新订阅 + 5 秒重试 3 次。

**设备与安全**
- 设备指纹（平台+硬件+盐哈希）上报；我的页设备管理（查看/踢下线）；
- 设备数超限 → 提示删除旧设备或购买设备升级包（后端已有 `/orders/upgrade-devices`）；
- Token 存 `flutter_secure_storage`；日志脱敏（不打 token/订阅链接全文）。

**提醒与通知**
- 订阅到期：7 天/3 天/1 天/当天 4 级提醒（每日一次）；点击直达充值页；
- 连接异常通知（断线重连失败 N 次后提示）；公告通知（后端 `/notifications`）。

**系统集成**
- 托盘（桌面）：连接/断开、当前节点、模式、退出；图标随状态变色；
- 开机自启（三端引导）；启动时自动连接（开关）；
- 检查更新：启动 + 每日一次，读 `/software-config`，弹更新弹窗（可选强制更新）；
- 深色/浅色/跟随系统；简体中文/English（后续可加更多）；
- 崩溃上报 Sentry（默认关）、匿名统计（默认关）。

**边界情况**
- 无网络/飞行模式：按钮置灰，提示先联网；
- 后端不可达：登录/订阅/支付全部中文错误 + 重试按钮；
- 订阅过期但隧道在跑：提示续费不强制断；
- 连接中被来电/系统提醒打断：Android VpnService 自动恢复；
- 时间不同步导致 JWT/证书校验失败：提示校准时间；
- 低电量：暂停后台测速与自动刷新，仅保留连接保活。
